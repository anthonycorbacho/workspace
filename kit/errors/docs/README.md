# Errors

When a request to Workspace fails, the response contains a unique error code (eg: `ERR_00000`) identifying the error, along with a message and details.
Include this code when contacting support at [support@example.com](mailto:support@example.com).

## Common errors

| Code | Message |
| --- | --- |
| [ERR_00000](err_00000.md) | internal error |
| [ERR_00001](err_00001.md) | invalid request |
| [ERR_00003](err_00003.md) | the request is not authenticated |
| [ERR_00004](err_00004.md) | permission denied |
